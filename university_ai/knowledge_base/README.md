# База знаний личного кабинета

Назначение: эти файлы используются LLM-ассистентом для ответов на вопросы пользователей о личном кабинете учебного заведения. Это справочная база, а не выгрузка данных пользователей и не API.

## Что читать

1. [assistant.md](assistant.md) — роль ассистента, правила ответа и ограничения. Загружать всегда.
2. [system.md](system.md) — назначение, состав и общие понятия системы.
3. [roles-and-access.md](roles-and-access.md) — роли, разрешения и лицензия. Загружать при вопросах «могу ли я?», «почему не вижу?», «кому доступно?».
4. [features.md](features.md) — модули и возможности. Загружать по названию функции.
5. [user-guides.md](user-guides.md) — короткие инструкции для типовых действий.

## Область действия и актуальность

Описание составлено по backend-репозиторию `lk` и frontend-репозиторию `lk_front` на 2026-09-14. Оно описывает реализованную структуру приложения, а не гарантирует, что конкретная функция включена у конкретного заказчика. Фактические данные, статусы заявок, оценки, расписание, состав ролей и текущий тариф нужно получать из авторизованного приложения, если у ассистента есть отдельный разрешённый инструмент. Если такого инструмента нет — не утверждать, что данные проверены.

При изменении продукта обновляйте соответствующий файл и дату здесь. Старые технические заметки в корне `lk` и `lk_front/docs` могут описывать отдельные версии функций; при конфликте для поведения системы проверяйте актуальный код и работающий интерфейс.

## Подключение к LLM

- В системный контекст передавайте `assistant.md`; `system.md` можно держать в базовом контексте. Остальные файлы извлекайте по теме вопроса с сохранением имени файла как источника.
- Индексируйте **только** утверждённые файлы из этой папки, а не весь репозиторий: рядом с кодом могут находиться конфигурация, лицензии и другие закрытые файлы.
- При разбиении на фрагменты сохраняйте заголовок раздела и путь к файлу. Для ответа с конкретным фактом желательно указывать название использованного файла, если интерфейс ассистента поддерживает ссылки на источники.
- Динамические сведения подключайте отдельным авторизованным инструментом с правами текущего пользователя. Без него ассистент должен давать инструкцию, где сведения посмотреть, а не генерировать их.
