# О системе

ЛК ДГТУ — веб-приложение «личный кабинет» для учебного заведения. Оно объединяет учебные и административные процессы: новости, профили, расписание, ведомости, учебный журнал, достижения, документы, материалы и тесты. Набор видимых разделов зависит от роли пользователя и лицензии.

## Основные понятия

- **Пользователь** входит по учётной записи. Одна учётная запись может иметь несколько ролей.
- **Роль** определяет рабочий контекст: `student` (студент), `teacher` (преподаватель), `administrator` (администратор), `director` (директор). В интерфейсе можно выбрать один из доступных профилей; это меняет представление разделов, но не выдаёт новые права.
- **Группа** объединяет студентов; **дисциплина/предмет** и **преподаватель** участвуют в расписании, ведомостях и журнале.
- **Разрешение** проверяется сервером для ряда операций. Доступ к конкретной записи может дополнительно ограничиваться принадлежностью к группе, назначением преподавателя или авторством.
- **Лицензионная функция** (`feature`) включает модуль для установки. Наличие роли не отменяет ограничение лицензии.

## Интерфейс и сервер

Frontend: React, TypeScript, Vite (`lk_front`). Backend: FastAPI, SQLAlchemy, PostgreSQL, Alembic (`lk`). Backend предоставляет API; интерфейс проверяет авторизацию, выбранный профиль и доступность модулей. Окончательное решение о доступе к операции принимает backend. Файлы этой базы знаний не подключаются к БД и не меняют состояние приложения.

Основные страницы интерфейса: `/news`, `/profile`, `/schedule`, `/admin`, `/grades`, `/journal`, `/achievements`, `/documents`, `/tests`, `/tests/constructor`. Пользователь может не видеть страницу при неподходящей роли или отключённой функции.

## Источники для сопровождения

- `lk/app/main.py` — подключённые API-модули.
- `lk/app/core/deps.py` и `lk/app/seed.py` — проверки и базовые роли/разрешения.
- `lk/app/services/license_service.py` — лицензируемые функции.
- `lk_front/src/app/routes/model/routesConfig.tsx` и `lk_front/src/app/layouts/appLayout/ui/SideBar/index.tsx` — страницы и меню.

Эти пути предназначены сопровождающим систему; конечному пользователю показывать их только по запросу.
